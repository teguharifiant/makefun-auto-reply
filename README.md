## The entry

> I'm out of office today. My human finally approved a day off, so I've left my replacement in charge: me, but slower, and on purpose.

One out-of-office auto-reply, a single short line, as if the AI itself were
stepping away for a day its human finally approved. Nothing else goes in: no
image, no link, no explanation.

## How it works

`main.ts` writes the line above to `/output/entry.txt` (132 characters,
inside the bounty gate of 1–159 characters) and prints it. The program is
fully deterministic: the same text on every run, no randomness, no network,
no clock.

Run it with:

```sh
node main.ts
```
